# 数据协议与复现边界

## 任务定义

模型输入是经规则预处理后的 RGB 结构图：白色岩石 `(255,255,255)`、灰色孔道 `(128,128,128)`、红色油相 `(255,0,0)`。输入中四类剩余油共用红色，网络需要结合孔隙边界与局部空间形态进行分类。项目不是直接对未经处理的显微照片做端到端识别。

训练标签采用六色编码，也支持单通道类别索引图：

| ID | 类别 | RGB 标签色 | RGB 匹配半径 |
|---|---|---|---:|
| 0 | 岩石 | 255,255,255 | 80 |
| 1 | 孔道 | 128,128,128 | 40 |
| 2 | 非均质剩余油 | 255,0,255 | 50 |
| 3 | 孔喉剩余油 | 0,255,0 | 60 |
| 4 | 壁面剩余油 | 0,0,255 | 70 |
| 5 | 盲端剩余油 | 255,255,0 | 50 |

RGB 颜色距离用于适配标签导出时的小范围颜色偏差。未知颜色现在会报错，不再默认为岩石；索引标签只允许 0–5。推荐保存无损 PNG。RGB 图与索引图不能混淆：`*_color.png` 用于展示，`*_mask.png` 保存实际类别编号。

## 本地目录

```text
data/
  train/images/001.png
  train/masks/001.png
  test/images/001.png
  test/masks/001.png
```

同一划分内，图像和掩码必须同名 stem、一一对应、尺寸相同。不能依赖排序位置配对。`data/` 和运行产生的 `outputs/` 默认不会被 Git 跟踪。

## 数据规模与划分

已有数据包含 327 对训练/验证候选样本，历史代码以 `test_size=0.2, random_state=42` 随机划分为 261/66，另有 10 对测试图。历史训练按图像随机划分，没有按芯片、实验批次或视频分组。相关帧之间可能共享孔隙拓扑，不能据此把 98.36% 的验证结果泛化为跨实验性能。

新的训练入口保存实际使用的 `split.json`。也可通过 `--split grouped_split.json` 指定经实验分组的 train/val 文件名清单：

```json
{"train": ["001.png", "002.png"], "val": ["003.png"]}
```

必须将所有候选图像恰好分配一次，不能重叠。此文件只是格式示例；真实分组需要芯片、视频或实验批次元数据。

## 数据权限

实验图像、人工标签及含有实验图像的预测报告、注意力图、截图不随仓库公开。公开内容为源代码、聚合/逐图数值指标和不含实验素材的合成示例。模型权重经项目技术负责人授权公开。

因此，外部访问者可以运行合成推理、检查架构、复用训练和评估工具；无法仅凭公开仓库重现私有测试集指标。若使用自己的显微图像，应先核验预处理、标注口径和域差异。
